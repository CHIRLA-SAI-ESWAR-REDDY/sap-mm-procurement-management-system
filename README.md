# SAP MM Procurement Management System using SAP S/4HANA Cloud Public Edition

## 📌 Project Overview

The **SAP MM Procurement Management System** is an end-to-end procurement management project developed using **SAP S/4HANA Cloud Public Edition**.

The project demonstrates how an organization can manage its procurement lifecycle using SAP Materials Management (MM), starting from purchasing requirements and master data through purchase requisitions, purchase orders, goods receipts, supplier invoices, inventory management, and purchasing monitoring/reporting.

The implementation uses realistic procurement scenarios and sample enterprise data available within the SAP S/4HANA Cloud trial environment.

---

## 🎯 Project Objectives

- Understand the SAP MM procurement lifecycle.
- Configure and work with procurement-related master data.
- Create and monitor purchasing documents.
- Demonstrate the Procure-to-Pay (P2P) process.
- Process goods receipts and inventory movements.
- Process supplier invoices and their accounting follow-on documents.
- Monitor purchase requisitions and purchase orders.
- Analyze inventory and material documents.
- Explore purchasing analytics and reporting capabilities.
- Document the complete implementation using screenshots and technical documentation.

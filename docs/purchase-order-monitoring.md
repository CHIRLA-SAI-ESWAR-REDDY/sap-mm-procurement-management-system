\# Purchase Order Monitoring



\## Overview



Purchase Order Monitoring is used to track and analyze purchase order items in SAP S/4HANA Cloud. It provides visibility into open purchase orders, suppliers, materials, delivery status, and procurement values.



This activity demonstrates monitoring purchase order items and displaying an individual purchase order using the SAP purchasing applications.



\---



\## 1. Monitor Purchase Order Items



The \*\*Monitor Purchase Order Items\*\* application provides an overview of purchase order items and allows users to filter and analyze procurement data.



\### Key Filters



\- Purchase Order

\- Supplier

\- Material

\- Plant

\- Next Schedule Line Date

\- Next Delivery Status

\- Upcoming Deliveries

\- Predicted Delivery

\- Order Status

\- Order Date

\- Fully Delivered \& Invoiced

\- Display Currency



\### Monitoring Dashboard



The monitoring dashboard provides graphical analysis of purchase order values.



The dashboard can group purchase order items by material group and display:



\- Net Order Value

\- Value to be Delivered

\- Value to be Invoiced



The project captured a monitoring result containing thousands of purchase order items for analysis.

Purchase Order Monitoring supports the procurement lifecycle by providing visibility into:
